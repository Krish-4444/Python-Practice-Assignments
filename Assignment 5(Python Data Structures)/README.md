# Assignment 5: Python Data Structures

This folder contains clean and well-documented Python scripts for all 20 Data Structures problems covering **Tuples**, **Sets**, and **Dictionaries**:

| Program File | Topic / Description |
|---|---|
| [Tuple_Set.py](file:///e:/skytus%28Intenship%20Assignment%29/Assignment%205%28Python%20Data%20Structures%29/Tuple_Set.py) | **Tuples & Sets**: Handling tuple creation, indexing, unpacking, set operations (union, intersection, subset, add/remove elements), and list deduplication. |
| [Dictionary.py](file:///e:/skytus%28Intenship%20Assignment%29/Assignment%205%28Python%20Data%20Structures%29/Dictionary.py) | **Dictionaries**: Dictionary creation, key-value modification/deletion, merging dictionaries, key lookup, word frequency counter, max key identification, key-value reversal, and tuple list conversion. |

---

### Detailed Problem Breakdown

#### 1. Tuples & Sets (`Tuple_Set.py`)
- **Tuple Operations**:
  - Create a tuple with 5 numbers.
  - Access the third element in a tuple.
  - Unpack a tuple into separate variables.
- **Set Operations**:
  - Create a set of 5 fruits.
  - Add a new fruit to the set.
  - Remove an element from a set.
  - Find union of two sets.
  - Find intersection of two sets.
  - Check if one set is subset of another.
  - Convert a list with duplicate values into a set to remove duplicates.

#### 2. Dictionaries (`Dictionary.py`)
- **Dictionary Operations**:
  - Create a dictionary storing student names and marks.
  - Add a new key-value pair to an existing dictionary.
  - Delete a key-value pair from a dictionary.
  - Merge two dictionaries into one.
  - Check if a key exists in a dictionary.
  - Count word frequency in a given string using a dictionary.
  - Find the key with the maximum value in a dictionary.
  - Reverse keys and values in a dictionary.
  - Update the value for a specific key.
  - Convert a list of tuples into a dictionary.
