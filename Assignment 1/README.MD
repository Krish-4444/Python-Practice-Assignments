# Python Beginner Practice Programs

This repository contains my **Python beginner practice programs**.

A collection of beginner-friendly Python programs created to strengthen my understanding of **Python fundamentals, user input, variables, operators, data types, and basic problem-solving.**

### Programs Covered

* Write a program to print your name, age, and city in one line.
* Take user input for two numbers and print their sum.
* Write a program to convert temperature from Celsius to Fahrenheit.
* Store your name in a variable and print it in uppercase.
* Ask the user for their birth year and calculate their current age.
* Write a program to swap the values of two variables.
* Create a program to calculate the area of a rectangle from user inputs.
* Write a program to check if a number is positive or negative.
* Ask for two numbers and print their average.

🎯 **Learning Objectives**

Through these programs, I practiced:

* Understanding Python syntax
* Declaring and using variables
* Taking input from users
* Converting input using `int()` and `float()`
* Performing arithmetic operations
* Working with strings
* Using string methods
* Writing conditional statements
* Solving basic mathematical problems
* Developing logical thinking and problem-solving skills
* Running Python programs from the terminal
