# Assignment 13 (Project)

This directory contains 2 mini Python projects built as part of Assignment 13.

## Projects Included:

1. **Bank Management System** (`proj2_bank_system.py`)
   An Object-Oriented approach to a basic banking system where users can create an account, deposit money, withdraw money, and check their balance.
 
2. **Weather App** (`proj4_weather_app.py`)
   A simple script that fetches current weather data for any city using a free, public JSON API (`wttr.in`).

## How to Run

1. Open your terminal or command prompt.
2. Navigate to this directory.
3. Run a specific script, for example:
   ```powershell
   python proj2_bank_system.py
   ```
