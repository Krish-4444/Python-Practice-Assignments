#  Python Beginner Practice Programs

This repository contains my **Python Assignment 2 practice programs**.

A collection of beginner-friendly Python programs created to practice **operators, conditional statements, type conversion, and basic problem-solving**.

## 📚 Programs Covered

1. Calculate the remainder of two numbers.

2. Check if a number is even or odd.

3. Compare two numbers and print the larger one.

4. Calculate the square and cube of a number.

5. Check if two entered numbers are equal.

6. Take two numbers and print `True` if both are positive, else `False`.

7. Convert a float value to an integer.

8. Take a number as a string, convert it to `int`, and multiply it by 10.

9. Use `and` and `or` operators to check multiple conditions.

10. Divide two numbers and print the quotient and remainder separately.

## 🛠️ Technologies

* Python 3

* Git & GitHub
* PowerShell / Terminal
